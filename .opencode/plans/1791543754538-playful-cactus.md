# Sync and Docs Plan

## Architecture
- `docs/`: Tracked. Contains source files (Markdown, Typst, scripts). Only edited on laptop, pushed to VPS.
- `docs/images/`: Tracked. Contains static images/diagrams (e.g. `lmm.png`).
- `data/`: Untracked. Contains dataset, `optuna.db`, `model_checkpoints/`, `figures/`. Generated by VPS.
- Sync: Git for code/docs. `rsync data/` from VPS to laptop.

## Build Steps
1. Update Python scripts to save models to `data/model_checkpoints/` and plots to `data/figures/`. [COMPLETED]
2. Spawn agent to translate `docs/TFG.md` to `docs/TFG.typ`. [COMPLETED]
3. Reorganize existing images:
   - Move static diagrams (like `lmm.png`) to `docs/images/`.
   - Ensure generated plots are moved to `data/figures/` (if locally available).
4. Update `docs/TFG.typ` image paths:
   - Change static image paths to `images/lmm.png`.
   - Change generated plot paths to `../data/figures/plot_name.png`.
